# Wireless Communication and Networks Laboratory

Lab work for **Wireless Communication and Networks Laboratory** (B.Tech ECE, 6th semester, Amrita School of Engineering, Bengaluru).

## Experiments include
- **TCP client-server chat in C** with Winsock socket programming: connection set-up, reliable ordered delivery, and a server that broadcasts messages to multiple clients
- **RDS (Radio Data System) extraction from FM broadcasts** with an RTL-SDR: tuning, FM demodulation, isolating the 57 kHz RDS subcarrier, decimation and filtering, BPSK demodulation, clock recovery and decoding of station metadata
- Further networking and wireless experiments documented in the report

- `WCN_ENDSEM_REPORT_2.pdf` — end-semester lab report with aim, theory, procedure, code, outputs and conclusions
